## 📋 Etapas do 
    projeto

### Etapa 1 — Pesquisa de Sites de ONGs de Animais
Pesquisa e análise de 3 a 5 sites de ONGs de proteção e adoção de animais,
com descrição das características de cada um.### Etapa 2 — Análise de UX / UI com Auxílio de IA
Uso de ferramenta de Inteligência Artificial generativa para extrair boas práticas de UX / UI dos sites pesquisados,
com reflexão crítica do 
    grupo sobre as sugestões obtidas.### Etapa 3 — Wireframe do 
        Protótipo
Desenvolvimento do 
    wireframe de pelo menos 3 páginas do 
        site(Home, Animais para Adoção e Contato / Sobre),
        representando a estrutura e o layout planejados.### Etapa 4 — Esboço do 
            Código HTML
Criação da estrutura semântica das páginas em HTML5 e CSS,
sem uso de JavaScript,
seguindo o wireframe desenvolvido na etapa anterior.## 🚀 Como contribuir
